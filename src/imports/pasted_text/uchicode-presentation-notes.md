Доработай презентацию Uchicode по тексту и заметкам.

Главное:
На слайдах должно быть мало текста.
Заметки докладчика должны быть короткими, понятными и по сути.
На последнем слайде сделай отдельную шпаргалку для выступления, чтобы её можно было сфотографировать на телефон и быстро читать перед защитой.

Правила для текста на слайдах:

1. Один слайд — одна мысль.
2. Заголовок до 5–7 слов.
3. Тезис под заголовком — одна короткая строка.
4. Пункты — максимум 3, редко 4.
5. Каждый пункт — 2–5 слов.
6. Не использовать длинные предложения.
7. Не повторять одинаковые слова на каждом слайде: “платформа”, “обучение”, “практика”, “помогает”.
8. Не писать абзацы на слайдах.
9. Всё подробное вынести в заметки.

Правила для заметок докладчика:

1. На каждый слайд 3–5 коротких предложений.
2. Без длинных абзацев.
3. Без сложных технических формулировок.
4. Текст должен звучать естественно, как речь студента.
5. В заметках объяснять только суть: что показать, зачем этот слайд нужен, какой вывод сделать.
6. Не растягивать речь. Лучше чётко и уверенно.
7. Не повторять одно и то же разными словами.

Пример длины заметок на один слайд:
“На этом слайде я показываю, что Uchicode — это учебная платформа по C++. Её задача — помочь новичку учиться не хаотично, а по понятному маршруту. В проекте есть курсы, темы, задачи, AI-советник, профиль и прогресс.”
