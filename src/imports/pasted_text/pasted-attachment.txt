Что известно и обязательно нужно отразить, если это подтверждается источниками:
Uchicode — учебная платформа по C++ для новичков.
В проекте есть курсы «База C++» и «ООП C++».
Платформа строит маршрут обучения через короткую теорию, рабочий пример, частые ошибки, практическую задачу и самопроверку.
Есть публичная главная страница без app-shell.
Есть рабочая учебная зона с курсами, задачами, guide/common errors и auth/profile страницами.
Страницы теории используют единый подход к контенту и CodeBlock.
Есть каталог задач, task detail flow и starter code на странице задачи.
AI assistant находится внутри учебной зоны, но не должен подаваться как главная ценность проекта.
Архитектура проекта: React + TypeScript + Vite на frontend, Django на backend, production через Docker Compose, host Nginx, PostgreSQL и Redis.

Визуальный стиль:
Современный, аккуратный, технологичный, но не перегруженный.

Используй стиль, который подходит для учебной защиты: чистые карточки, простые схемы, аккуратные подписи, без «стартап-пафоса».

Не перегружай слайды длинными абзацами.
Если текст не помещается, сокращай формулировки, а не уменьшай шрифт до неудобного размера.
